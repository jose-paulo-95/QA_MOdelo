# Charter exploratório

## Sobre este template

| | |
|---|---|
| **Objetivo** | Guiar uma sessão de teste **exploratório** com missão, tempo fechado e registro do que foi aprendido — para achar riscos que o script ainda não cobre. |
| **Quando usar** | Fluxo novo ou instável; regra ainda mudando no refinamento; além dos casos scriptados (nunca no lugar deles em R1). |
| **Quando não usar** | Para regressão permanente de risco financeiro (escreva `TC-`); para usabilidade com usuário do papel (use charter de usabilidade); para execução de aceite formal (use caso + Test Run). |
| **Quem preenche** | QA durante a sessão (ou pair). |
| **Entrada** | Missão clara, build, massa sintética, tempo máximo (ex.: 60–90 min). |
| **Saída** | Notas da sessão + novos `TC-` ou defeitos + o que permanece só exploratório. |
| **Próximo passo** | Transformar achados relevantes em [caso-de-teste.md](caso-de-teste.md) ou [defeito.md](defeito.md). |
| **Referência** | [02-modelo-de-qualidade-e-modelagem.md](../02-modelo-de-qualidade-e-modelagem.md) (técnica baseada em experiência), CTAL-AT |

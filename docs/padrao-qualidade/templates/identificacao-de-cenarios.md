## Sobre este template

| | |
|---|---|
| **Objetivo** | Descobrir *quais* condições testar (negócio × canal), com decisão incluir/adiar/automatizar e IDs `CT-` sugeridos — sem ainda detalhar todos os passos. |
| **Quando usar** | Após a avaliação de risco; ao receber requisito novo; ao pedir à skill `identificar-cenarios-teste`. |
| **Quando não usar** | Quando os `TC-` já existem e só precisam de manutenção; ou para registrar defeito/execução (use defeito/relatório). Não substitui o caso de baixo nível. |
| **Quem preenche** | QA. Pode ser preenchido com apoio do agente e validado pelo QA. |
| **Entrada** | Requisito + [avaliacao-de-risco.md](avaliacao-de-risco.md) (mesmo que parcial). |
